# Control LED Button

## Deskripsi
Project Arduino Uno untuk mengontrol LED menggunakan push button.
Terdiri dari 3 tahap: 1 LED, 2 LED, dan 3 LED.

## Hardware
- Arduino Uno
- 3 LED
- 3 Push Button
- 3 Resistor 220 Ohm
- Breadboard
- Jumper Wire

## Pin Configuration
- LED 1: D8, Button 1: D2
- LED 2: D9, Button 2: D3
- LED 3: D10, Button 3: D4
